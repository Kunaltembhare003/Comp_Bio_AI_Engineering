# Comp Bio AI Engineering

This project brings together computational biology concepts with AI and engineering workflows. The goal is to organize research, tooling, and practical experiments into a clean documentation site.

## Project goals

- Document the project structure and workflow clearly.
- Capture key concepts from computational biology and AI engineering.
- Provide a reproducible reference for future experiments and research.

## Repository layout

- `Material/`: supporting learning materials and references.
- `plan/`: planning notes and design documentation.
- `README.md`: repository-level project overview.

## Quick links

- [Getting Started](getting-started.md)
- [Project Plan](plan.html)

## Local documentation

To build the docs locally:

```bash
python3 -m pip install -r requirements.txt
mkdocs serve
```

The site will be available at http://127.0.0.1:8000 while the development server is running.
